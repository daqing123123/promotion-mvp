# 巨浪 — 平台定位

## 一句话定位

**巨浪是一个内容商城 + 社交裂变平台，让用户一边刷一边赚，帮好内容找到对的人。**

## 核心比喻

巨浪就像一个商店，里面卖的不是实物，而是各种"内容商品"：

- 🧑 **个人的知名度** — 你的作品、观点、技能被更多人看到
- 📦 **产品** — 好物推荐、软件工具、AI Agent
- 🎯 **技能/Skill** — 你会什么，能帮别人解决什么问题
- 🤖 **Agent** — 你做的 AI 助手，别人可以直接用
- 🎬 **内容** — 段子、文章、视频、观点、新闻

品牌和个人发布活动，就像商场做促销活动。用户转发帮推，就像朋友圈集赞——但不是白帮忙，有积分奖励。

## 四种角色

| 角色 | 类比 | 动机 | 收益 |
|------|------|------|------|
| **品牌/商家** | 开店的 | 低成本推广，精准触达用户 | 曝光、转化、用户反馈 |
| **创作者/个人** | 摆摊的 | 展示才华，积累粉丝和影响力 | 积分、粉丝、变现机会 |
| **普通用户** | 逛街的 | 发现好内容，顺便赚点奖励 | 积分、成就感、社交货币 |
| **帮推者** | 集赞达人 | 帮好内容扩散，赚积分 | 积分、等级提升 |

## 核心驱动力

### 用户端：一边刷一边赚

```
刷 Feed → 发现好内容 → 点赞/评论/帮推 → 获得积分 → 兑换奖励
```

用户不是被动消费内容，而是主动参与内容的传播和筛选。每一次互动都有价值。

### 创作者端：被看见的价值

```
发布内容 → 获得曝光 → 积累粉丝 → 建立影响力 → 变现
```

创作者不需要自己推广，平台的帮推机制让好内容自然扩散。

### 品牌端：社交裂变引擎

```
发布活动/任务 → 用户参与 → 用户帮推 → 社交裂变 → 低成本高曝光
```

品牌不用花大钱买广告，用积分激励用户主动传播，效果更好成本更低。

## 与传统平台的区别

| | 传统内容平台 | 巨浪 |
|---|---|---|
| 用户角色 | 消费者 | 消费者 + 推广者 + 评判者 |
| 内容分发 | 算法决定 | 算法 + 用户帮推双重分发 |
| 创作者收益 | 平台分成（门槛高） | 积分 + 粉丝 + 帮推收益（人人可得） |
| 品牌推广 | 花钱买流量 | 积分激励用户自发传播 |
| 用户激励 | 沉默消费 | 每次互动都有积分回报 |

## 内容类型

平台支持多种内容形态，每种都有专属的展示和交互方式：

- 📝 **段子/梗** — 短平快，适合传播和二创
- 📦 **产品** — 好物推荐，带试用和反馈系统
- 🎯 **技能/Skill** — 你会什么，展示出来
- 🤖 **Agent** — AI 助手，可直接体验
- 🎬 **影视/音乐** — 娱乐内容，引发讨论
- 📰 **新闻/观点** — 热点话题，引发思考
- 🆘 **求助/问答** — 社区互助
- 🤝 **交友** — 找到同频的人

## 活动机制

品牌和个人可以发布活动，用户参与活动获得奖励：

- 🏆 **话题活动** — 围绕话题创作内容，优秀内容获得额外奖励
- 📋 **任务活动** — 完成指定任务（转发、评论、创作）获得积分
- 🗳️ **投票活动** — 用户投票表达观点，参与感拉满
- 🎁 **试用活动** — 免费试用产品，写真实反馈

活动就像商场促销，但用户不是被动接受，而是主动参与和传播。

## 帮推机制

帮推是巨浪的核心裂变引擎：

1. 用户发现好内容 → 点击"帮推"
2. 内容被分享到用户的社交圈
3. 新用户通过分享链接进入平台
4. 帮推者获得积分奖励
5. 内容获得更多曝光

帮推不是简单的"转发"，而是一种有回报的内容推荐行为。

## 积分经济

积分是平台的通用货币：

| 行为 | 积分 |
|------|------|
| 每日签到 | +10 |
| 点赞 | +5 |
| 评论 | +5 |
| 帮推 | +20 |
| 发布内容 | +10 |
| 完成任务 | +50~200 |
| 连续签到 3 天 | +20 额外 |
| 连续签到 7 天 | +50 额外 |
| 连续签到 30 天 | +200 额外 |

积分可以用来：
- 参与投票（消耗积分表达立场）
- 兑换奖励（优惠券、实物、虚拟商品）
- 提升等级（等级越高，权益越多）

## 等级系统

1-100 级，指数增长，越高等越难升：

- Lv.1-10：新手，熟悉平台
- Lv.11-30：活跃用户，开始建立影响力
- Lv.31-60：核心用户，有一定粉丝基础
- Lv.61-90：大V，平台意见领袖
- Lv.91-100：传说级，几乎不可能达到

等级不只是数字，代表你在平台的影响力和贡献度。
