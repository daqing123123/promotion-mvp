# 内容页交互规范

> 手机屏幕装不下所有内容，也不需要。核心原则：分层展示，逐步展开。

---

## 三层结构

```
第一层：Feed 流（一屏）     → 看一眼就懂，决定要不要点进去
第二层：内容页（滑动看）    → 核心信息，决定要不要用
第三层：详情页（展开看）    → 完整信息，给需要的人
```

## 三、详情页（第三层）

点击"展开"按钮进入，完整信息。

### 产品详情页

- 全部商品图片
- 完整参数表
- 全部用户评价
- 商家信息（店铺等级、评分）
- 相关推荐

### Skill 详情页

- 权限详情（每个权限的用途说明）
- 版本历史（更新日志）
- 全部用户评价
- 使用教程
- 相关Skill推荐

### Agent 详情页

- 完整介绍（Markdown长文）
- 对话示例（更多场景）
- 用户评价
- 相关Agent推荐

## 四、交互页（使用层）

用户决定使用后进入的页面。

### 产品 → 购买/试用

- **购买**：跳转外部链接（淘宝/京东/自营）
- **试用**：弹出确认框 → 报名试用 → 等待中奖通知

### Skill → 安装/试用

- **安装**：弹出确认框（显示权限）→ 确认 → 下载安装
- **试用**：进入沙箱演示页（sandbox模式运行，不装到本地）

### Agent → 对话

- 直接进入对话界面
- 底部输入框，顶部对话历史
- 首次进入自动发送欢迎语

```

│  ← 旅行规划师         │
```

## 五、加载策略

不一次性加载所有内容，用户看到哪加载哪。

| 层 | 加载时机 | 内容 |
|---|---------|------|
| Feed 卡片 | 进入Feed | 封面图 + 标题 + 按钮 |
| 内容页 | 点击卡片 | 核心信息 + 3条热评 |
| 详情页 | 点击"展开" | 完整参数/权限/评价 |
| 交互页 | 点击"使用" | 对话界面/安装确认 |
