# 巨浪核心玩法设计

> 一边刷，一边赚。刷是娱乐，赚是动力，帮推是手段。
>
> 在巨浪，刷视频不是消磨时间，是在赚钱。

---

## 核心循环

```
刷内容 → 发现任务/好内容 → 帮推/完成任务 → 获得积分/奖励
  ↑                                              ↓
  └──── 积分换现金/实物 ← 等级提升 ← 成就解锁 ←──┘
```

---

## 一、积分经济（核心）

### 1.1 积分获取

| 行为 | 积分 | 说明 |
|------|------|------|
| 每日签到 | 10 | 基础活跃 |
| 刷内容（每10条） | 5 | 鼓励消费，每日上限50 |
| 帮推成功 | 20-100 | 核心行为，按效果给 |
| 帮推的内容火了 | 额外奖励 | 裂变激励 |
| 完成试用反馈 | 50-200 | 高价值行为 |
| 发布内容被帮推 | 10-50 | 创作者激励 |
| 连续活跃（7天） | 100 | 留存 |
| 邀请好友注册 | 200 | 拉新 |
| 好友首次帮推 | 50 | 裂变 |

### 1.2 积分消费

| 消费 | 积分 | 说明 |
|------|------|------|
| 兑换现金 | 1000积分 = 1元 | 核心吸引力 |
| 兑换实物 | 按商品定价 | 平台试用商品也可兑换 |
| 抽奖 | 100积分/次 | 盲盒、大额奖品 |
| 解锁特权 | 按等级 | 高等级解锁更多任务 |
| 帮推加速 | 50积分 | 花积分让帮推获得更多曝光 |
| 内容推广 | 100积分起 | 创作者花积分推广自己的内容 |

### 1.3 积分防刷规则

| 规则 | 说明 |
|------|------|
| 每日帮推积分上限 | 500积分 |
| 每日刷内容积分上限 | 50积分 |
| 同一内容只算一次帮推 | 防止反复帮推刷分 |
| 帮推需产生真实曝光 | 无效果的帮推不给积分 |
| 异常行为检测 | 批量操作、机器行为 → 封号 |

## 二、任务系统

### 2.1 任务类型

| 类型 | 示例 | 奖励 | 来源 |
|------|------|------|------|
| 帮推任务 | "帮推这条视频，达到100播放" | 50积分 | 商家/平台 |
| 互动任务 | "给这条内容写评论" | 20积分 | 平台 |
| 试用任务 | "试用这个商品并写反馈" | 200积分+商品 | 商家 |
| 创作任务 | "发布一条视频" | 30积分 | 平台 |
| 每日任务 | "刷30条内容+3次帮推" | 100积分 | 系统 |
| 限时任务 | "双11帮推挑战" | 大额奖励 | 运营 |

### 2.2 每日任务（固定）

| 任务 | 条件 | 奖励 |
|------|------|------|
| 签到 | 打开App | 10积分 |
| 刷一刷 | 浏览30条内容 | 30积分 |
| 帮一帮 | 完成3次帮推 | 50积分 |
| 评一评 | 写2条评论 | 20积分 |
| 全勤奖 | 完成以上全部 | 额外50积分 |

**每日任务总计：160积分（全勤）**

## 四、等级体系

### 4.1 等级划分

| 等级 | 名称 | 累计积分 | 特权 |
|------|------|---------|------|
| Lv1 | 新手 | 0 | 基础任务 |
| Lv2 | 活跃 | 100 | 解锁帮推任务 |
| Lv3 | 达人 | 1,000 | 解锁高奖励任务、实物兑换 |
| Lv4 | 专家 | 5,000 | 专属任务、优先中奖 |
| Lv5 | 大V | 20,000 | 平台合作、专属客服 |

### 4.2 等级特权明细

**Lv2 活跃：**
- 解锁帮推任务（更高积分）
- 每日帮推积分上限提升至600

**Lv3 达人：**
- 解锁高奖励帮推任务（100积分/次）
- 可兑换实物商品
- 试用任务优先分配

**Lv4 专家：**
- 专属高奖励任务池
- 试用中奖概率 +50%
- 帮推效果数据看板

**Lv5 大V：**
- 平台合作机会（品牌任务）
- 专属客服
- 内容优先审核
- 参与平台内测

## 五、排行榜

### 5.1 排行榜类型

| 榜单 | 排序依据 | 奖励 |
|------|---------|------|
| 帮推榜 | 本周帮推次数 | TOP10额外积分 |
| 赚钱榜 | 本周赚取积分 | TOP10额外积分 |
| 伯乐榜 | 帮推命中率（火了/总帮推） | TOP10称号 |
| 创作榜 | 本周内容热度 | TOP10流量扶持 |

### 5.2 排行榜周期

- 日榜：每日更新，奖励较小
- 周榜：每周更新，奖励适中
- 月榜：每月更新，奖励丰厚

## 六、商业闭环

```
用户刷内容 → 做帮推任务 → 内容被传播
                              ↓
商家付费投放 ← 商家看到效果 ← 传播数据好
      ↓
商家继续投放 → 平台收入 → 分给用户积分
                              ↓
用户用积分换现金/实物 → 用户继续刷
```

### 6.1 各方收益

| 角色 | 收益 |
|------|------|
| 用户 | 积分换现金/实物 + 成就感 + 娱乐 |
| 商家 | 真实用户传播 + 用户反馈 + 品牌曝光 |
| 平台 | 商家投放费用 - 用户积分成本 = 利润 |

### 6.2 平台收入来源

| 来源 | 说明 |
|------|------|
| 帮推任务佣金 | 商家发布帮推任务，平台抽成 |
| 试用活动费用 | 商家发起试用，平台收取服务费 |
| 广告收入 | Feed流中插入广告 |
| 会员服务 | 高级会员享更多特权 |
| 电商佣金 | 试用后购买的分成 |

### 6.3 积分成本控制

- 每日积分发放有上限
- 积分兑换现金有最低门槛（1000积分起兑）
- 积分有效期（1年过期）
- 根据平台收入动态调整积分获取比例

## 七、用户一天的典型场景

```
早上打开巨浪 → 签到（+10积分）
    ↓
刷几条内容 → 偶然看到有趣的视频（+5积分）
    ↓
觉得值得推荐 → 点帮推（+50积分，如果火了额外奖励）
    ↓
看到帮推任务 → "帮推XX视频，奖励100积分" → 完成
    ↓
刷到试用任务 → "免费领XX商品，写反馈+200积分" → 报名
    ↓
完成每日全部任务 → 全勤奖（+50积分）
    ↓
查看排行榜 → 发现自己在帮推榜TOP20 → 有成就感
    ↓
积分够了 → 兑换了10元现金 / 一个小商品
    ↓
明天继续
```

## 八、冷启动策略

平台初期没有商家投放时：

| 策略 | 说明 |
|------|------|
| 平台自掏腰包 | 初期积分兑换由平台补贴，建立用户习惯 |
| 免费试用合作 | 找小商家免费合作，用平台流量换商品 |
| 邀请奖励 | 邀请好友注册双方都得积分 |
| 创作者激励 | 优质内容创作者签约，保底收入 |
| 每日签到大奖 | 初期签到奖励翻倍，培养打开习惯 |
