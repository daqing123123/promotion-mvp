# 商家试用与反馈系统 — 设计方案

> 用免费试用建立信任飞轮，三方共赢。

## 核心循环

```
商家拿出商品 → 平台筛选用户 → 用户试用 → 用户给反馈
     ↑                                          ↓
     └──── 商家等级提升 ← 反馈质量高 ←──────────┘
```

**三方共赢：**
- 商家：拿到真实反馈 + 曝光
- 用户：拿到免费商品 + 信任感
- 平台：拿到数据 + 活跃度 + 内容生产素材

---

## 1. 商家分档机制

| 档位 | 商品数量 | 对应商家阶段 | 说明 |
|------|---------|-------------|------|
| 一档 | 10 | 新店试水 | 门槛低，鼓励参与 |
| 二档 | 50 | 有一定口碑 | 需要一档反馈达标才能升 |
| 三档 | 200 | 优质商家 | 平台给更多曝光资源 |
| 四档 | 定制 | 品牌合作 | 专属活动页、联名推荐 |

### 升档条件

- 当前档位的反馈平均分 ≥ 4.0（5分制）
- 反馈采纳率 ≥ 60%（商家确认"有参考价值"）
- 无重大投诉或违规记录

### 降档条件

- 反馈平均分 < 3.0
- 用户投诉率 > 10%
- 送劣质商品或虚假商品

---

## 2. 用户分层抽取

| 用户类型 | 抽取比例 | 说明 |
|---------|---------|------|
| 优质用户 | 60% | 反馈历史好、活跃度高、信用分高 |
| 普通用户 | 40% | 新用户也有机会，保持公平感 |

### "优质用户"定义

| 维度 | 指标 | 权重 |
|------|------|------|
| 反馈质量 | 字数、图片、详细程度、被商家采纳次数 | 40% |
| 反馈速度 | 收到商品后 X 天内提交 | 20% |
| 信用 | 是否虚假反馈、是否转卖免费商品 | 25% |
| 活跃度 | 平台使用频率 | 15% |

### 优质用户判定门槛

- 至少完成 3 次试用反馈
- 平均反馈评分 ≥ 4.0
- 无违规记录

---

## 3. 反馈 → 概率提升机制

| 反馈质量 | 下次中奖概率变化 | 说明 |
|---------|----------------|------|
| 优秀（图文详实、有参考价值） | +50% | 但不超过普通用户的 2 倍上限 |
| 良好（基本描述完整） | +20% | |
| 一般（寥寥几句） | 不变 | |
| 差（敷衍/虚假） | -30% | 进入冷却期 |
| 未提交反馈 | -50% | 连续两次未提交 → 暂停资格 |

### 反馈质量评分标准

**优秀反馈（5分）：**
- 100字以上
- 至少3张实拍图
- 包含使用场景、优缺点分析
- 有改进建议

**良好反馈（4分）：**
- 50字以上
- 至少1张图
- 有基本使用感受

**一般反馈（3分）：**
- 20字以上
- 简单描述好坏

**差反馈（1-2分）：**
- 少于20字
- 无图
- 复制粘贴/无关内容

## 4. 商家等级体系

### 等级决定因素

| 因素 | 权重 | 说明 |
|------|------|------|
| 商品质量 | 40% | 用户反馈的平均评分 |
| 送出数量 | 20% | 累计送出越多，诚意越足 |
| 反馈采纳率 | 20% | 商家是否看了反馈并改进 |
| 用户复购率 | 20% | 试用后有多少人真的购买 |

### 等级权益

| 等级 | 权益 |
|------|------|
| Lv1 试水 | 基础试用活动 |
| Lv2 口碑 | 平台推荐位、活动优先参与 |
| Lv3 优质 | 专属活动页、帮推加权 |
| Lv4 品牌 | 联名推荐、定制活动、数据报告 |

---

## 5. 防作弊机制

### 用户端

- 收到商品未反馈 → 中奖概率大幅下降
- 虚假反馈（复制粘贴、无关内容）→ 降权 + 冷却期
- 转卖免费商品 → 永久取消资格
- 异常地址（同一地址多次中奖）→ 审核

### 商家端

- 送劣质商品 → 差评多 → 降级
- 刷单送假商品 → 封店
- 虚假商品描述 → 用户投诉 → 降级

### 平台端

- 抽取过程透明化
- 用户能看到"本次抽取由系统随机，60%名额分配给优质用户"
- 定期公示防作弊数据

## 6. 与巨浪内容生态的联动

这是核心价值 — 试用系统不是独立电商功能，而是内容生产的发动机。

### 联动场景

| 场景 | 机制 | 效果 |
|------|------|------|
| 开箱/测评内容 | 用户发试用相关内容 → 获得积分 + 曝光双重奖励 | 内容生产 |
| 帮推传播 | 好的测评被帮推 → 商家和用户都获益 | 裂变传播 |
| 试用挑战 | 商家发起试用挑战，用户参与内容创作 | 活跃度 |
| 商家内容 | 商家发布产品介绍/使用教程 → 试用用户可以参考 | 内容丰富度 |

### 内容激励

- 发布试用测评内容 → 额外积分奖励
- 测评内容被帮推 → 额外曝光奖励
- 测评内容被商家采纳 → 解锁"试用达人"成就
- 优质测评进入"试用精选"频道 → 更多曝光

## 7. 流程概览

```
商家发起试用活动（选商品、选档位）
    ↓
平台审核商品（质量、描述真实性）
    ↓
活动上线，用户报名/自动抽取
    ↓
平台通知中奖用户，收集地址
    ↓
商家发货
    ↓
用户收到商品，提交反馈
    ↓
平台评分反馈质量，更新用户信用
    ↓
商家查看反馈，确认采纳
    ↓
双方等级/概率更新
    ↓
（可选）用户发布测评内容，获得额外奖励
```
