# 推荐经济系统设计

## 核心概念

```
发布内容/创意 → 被推荐 → 获得曝光+收益
推荐别人 → 获得推荐奖励
推荐 = 背书 = 信任传递
```

---

## 一、推荐机制

### 1. 推荐类型

| 类型 | 说明 | 消耗 |
|------|------|------|
| **免费推荐** | 点赞、转发、评论 | 无 |
| **付费推荐** | 真正的推荐背书 | 积分/现金 |
| **品牌推荐** | 品牌推荐达人 | 现金 |

### 2. 推荐等级

| 等级 | 条件 | 效果 |
|------|------|------|
| **普通推荐** | 消耗10积分 | 增加100曝光 |
| **强力推荐** | 消耗50积分 | 增加500曝光 |
| **超级推荐** | 消耗100积分+10元 | 增加2000曝光 |
| **品牌推荐** | 消耗500积分+100元 | 增加10000曝光 |

### 3. 推荐链

```
A推荐B → B获得曝光+A的推荐奖励
B推荐C → C获得曝光+B的推荐奖励
         A获得间接推荐奖励
```

---

## 二、收益模式

### 1. 被推荐收益

**场景**：你的内容/创意被别人推荐

**收益来源**：
- 推荐者消耗的积分 → 部分给被推荐者
- 推荐者消耗的现金 → 部分给被推荐者
- 平台补贴 → 根据推荐效果发放

**收益规则**：
```
被推荐收益 = 基础收益 × 推荐等级系数 × 内容质量系数

基础收益：10积分/次
推荐等级系数：普通1/强力2/超级5/品牌10
内容质量系数：根据浏览量、点赞量、转发量计算
```

### 2. 推荐收益

**场景**：你推荐别人的内容/创意

**收益来源**：
- 被推荐者获得的曝光 → 你获得推荐奖励
- 被推荐者获得的收益 → 你获得分成
- 平台奖励 → 推荐成功额外奖励

**收益规则**：
```
推荐收益 = 被推荐者收益 × 分成比例 + 推荐成功奖励

分成比例：10%
推荐成功奖励：被推荐者收益超过100元时，额外奖励50积分
```

### 3. 间接推荐收益

**场景**：你推荐的人又被别人推荐

**收益规则**：
```
间接推荐收益 = 被推荐者收益 × 间接分成比例

间接分成比例：5%
```

## 三、内容/创意发布

### 1. 内容类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **文字** | 纯文字动态 | 想法、观点、故事 |
| **图片** | 图文内容 | 作品、设计、照片 |
| **音乐** | 音频内容 | 配乐、翻唱、播客 |
| **视频** | 视频内容 | 短视频、Vlog、教程 |
| **创意** | 创意点子 | 推广创意、营销方案 |

### 2. 创意点子

**特殊内容类型**：用户可以发布"创意点子"

**特点**：
- 可以被品牌/企业购买
- 可以被推荐获得收益
- 可以被采纳获得奖励

**示例**：
```
创意：用AI生成品牌吉祥物
描述：用AI生成独特的品牌吉祥物，增加品牌辨识度
适用：品牌推广、产品推广
价格：100元
```

## 四、推荐位系统

### 1. 推荐位类型

| 类型 | 位置 | 获取方式 |
|------|------|----------|
| **热门推荐** | 首页顶部 | 钱+积分竞拍 |
| **新星推荐** | 首页中部 | 新用户专属 |
| **话题推荐** | 话题页顶部 | 话题任务奖励 |
| **品牌推荐** | 品牌页顶部 | 品牌付费 |

### 2. 推荐位竞拍

**规则**：
- 每天更新一次
- 竞拍价格 = 钱 + 积分
- 出价最高者获得推荐位
- 推荐位效果：增加曝光量

**示例**：
```
热门推荐位
起拍价：100元 + 1000积分
当前最高：500元 + 5000积分
竞拍截止：2026-05-01 00:00
```

## 七、等级系统

### 1. 等级划分

| 等级 | 积分 | 权益 |
|------|------|------|
| **新手** | 0-100 | 基础功能 |
| **达人** | 100-1000 | 可以推荐别人 |
| **专家** | 1000-5000 | 可以被品牌推荐 |
| **大师** | 5000-10000 | 可以购买推荐位 |
| **传奇** | 10000+ | 全部权益 |

### 2. 等级权益

- 达人：可以推荐别人，获得推荐收益
- 专家：可以被品牌推荐，获得品牌推荐收益
- 大师：可以购买推荐位，获得更多曝光
- 传奇：全部权益，优先推荐

## 八、完整流程

### 1. 用户发布内容

```
用户发布内容/创意
    ↓
内容进入内容池
    ↓
其他用户看到内容
    ↓
点赞/转发/推荐
    ↓
内容获得曝光
    ↓
用户获得收益
```

### 2. 推荐流程

```
用户A看到用户B的内容
    ↓
用户A推荐用户B（消耗积分/现金）
    ↓
用户B获得曝光+收益
    ↓
用户A获得推荐奖励
    ↓
用户B的内容被更多人看到
    ↓
更多人推荐用户B
    ↓
用户B获得更多收益
    ↓
用户A获得更多推荐奖励
```

### 3. 任务流程

```
品牌发布任务+话题
    ↓
用户看到任务
    ↓
用户发布内容带话题
    ↓
内容进入任务池
    ↓
内容被推荐
    ↓
根据效果获得奖励
```

## 九、收益分配

### 1. 收益来源

- 推荐消耗的积分
- 推荐消耗的现金
- 推荐位竞拍
- 品牌任务发布
- 平台补贴

### 2. 收益分配

```
总收益 = 被推荐者收益 + 推荐者收益 + 平台收益

被推荐者收益：60%
推荐者收益：30%
平台收益：10%
```

### 3. 结算方式

- 积分：实时到账
- 现金：每周结算
- 提现：满100元可提现
