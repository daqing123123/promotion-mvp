# 尊重创作者成果 — 设计原则与机制

> 帮推 = 尊重 + 回报 + 感谢，而不是搬运 + 抽血 + 抢流量

## 核心原则

不是限制传播，而是让传播变成一件"有回报"的事。

---

## 1. 溯源系统 — 每条内容都有"族谱"

每条内容都有不可抹去的来源链，系统自动关联，不需要用户手动 @。

```
用户A 发了原视频
  └─ 用户B 截取片段帮推 → 自动标注"来源：A 的 XX 视频"
      └─ 用户C 基于B的片段再创作 → 链条继续
          └─ 用户D 看到C的内容 → 能一键回溯到A
```

### 设计要点

- 来源标签由系统自动生成，不可手动删除
- 内容页可展开"创作链"，查看完整来龙去脉
- 每个节点都可点击跳转到原作

---

## 2. 流量反哺 — 传播即回报

| 场景 | 机制 |
|------|------|
| B 帮推 A 的内容火了 | A 获得该片段流量的一定比例曝光 |
| C 二创了 A 的内容 | C 的内容页展示 A 的原作入口，A 获得新流量 |
| 某个片段被大量截取 | 原作进入"热门素材"榜，获得更多推荐 |

**核心逻辑：你的内容被传播得越多，你获得的流量越大。正和博弈，不是零和。**

---

## 3. 知情权 — 创作者知道发生了什么

- **通知系统**："你的视频被 XX 截取了片段，已有 XX 人观看"
- **数据看板**：展示"谁在帮你推"、"哪段最火"、"带来多少新观众"
- **帮推链可视化**：创作者能看到完整的传播路径

---

## 4. 创作者控制权 — 创作者说了算

这是最核心的一条。

- **默认允许**帮推/二创，但提供**一键关闭**
- 关闭后"帮推"按钮变灰，提示"作者未开放帮推"
- 被帮推后，创作者可以**撤回授权**（已生成的内容下架或解除关联）
- 可按内容粒度控制（某条视频允许，某条不允许）

### 控制选项

| 选项 | 说明 |
|------|------|
| 允许帮推 | 其他用户可以截取片段并带来源传播 |
| 允许二创 | 其他用户可以基于此内容做续集/反应/改编 |
| 需要确认 | 帮推/二创需要作者审核通过才生效 |
| 关闭 | 不允许任何形式的二次使用 |

---

## 5. 经济回报（后期商业化阶段）

- 帮推内容产生的收益，原作者拿分成
- 二创内容打赏，原作者也能分到一部分
- "素材使用费"机制 — 热门素材被使用时，原作者获得积分/现金

---

## 6. 正向激励

- **帮推达人榜**：帮推最多/效果最好的用户，获得官方流量扶持
- **原创保护勋章**：高原创度内容获得平台标识，推荐加权
- **创作链成就**：你的内容被 X 人帮推，解锁成就徽章

---

## 反面教材（要避免的）

| 做法 | 问题 |
|------|------|
| 切片号泛滥 | 原作者拿不到回报，甚至被抢流量 |
| 二创不标注来源 | 观众以为是原创，原作者被埋没 |
| 平台不给创作者控制权 | 创作者觉得被平台绑架 |
| 只惩罚不奖励 | 创作者选择不发好内容，或者换平台 |

---

## 巨浪的机会

大多数平台是先野蛮生长，再补救。巨浪可以从第一天就把"尊重创作者"做成系统能力，成为平台的核心竞争力和信任基础。
